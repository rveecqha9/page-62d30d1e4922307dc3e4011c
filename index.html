品牌简介

NodeCat 是面向个人与团队的网络加速品牌，提供可订阅的机场服务与多端 VPN 加速能力。我们整合常规国际线路与 IPLC 专线资源，帮助用户更稳定地访问跨境办公、学术资料、流媒体与游戏节点。套餐、流量与设备额度在官方网站公示，订阅与客户端指引也集中在同一控制台完成。

NodeCat 官方网站用于查询套餐、获取订阅与下载客户端。请通过本站登录用户中心，避免使用来源不明的配置或修改包。旗舰版面向重度流媒体与游戏加速，团队版面向多设备与定制路由需求。

本页说明套餐构成、使用场景、导入步骤与常见问题，便于在手机上快速完成选型与上手。

使用场景

跨境远程办公

会议、网盘、协作文档与代码仓库访问时，可选择延迟更低的区域节点。旗舰版与团队版更适合长时间在线与多设备切换。企业如需固定出口或分流规则，可在团队版中申请定制路由。

学术检索与资料下载

访问期刊、预印本与公开数据集时，稳定连接比单纯追求峰值带宽更重要。基础版的普通线路节点池可覆盖轻量检索；大文件下载建议预留旗舰版流量并避开本地网络高峰。

流媒体与长视频

基础版提供基础流媒体解锁，满足常见站点的常规清晰度播放。对原生解锁与多地区内容有要求时，使用旗舰版或团队版的全节点解锁线路，并在客户端中开启相应地区节点。

游戏加速

对延迟与丢包敏感的对战与更新下载，优先使用带 IPLC 标识的游戏优化节点。旗舰版包含专线优化说明，适合晚高峰仍需相对稳定的链路。请以实际测速与游戏内延迟为准进行切换。

操作说明

完成购买后，在 NodeCat 官网用户中心复制订阅地址，再导入兼容客户端即可连接。推荐按下列顺序操作，减少配置错误。

  1. 打开 NodeCat 官方网站并注册或登录账号。
  2. 按设备数量与流量需求选择基础版、旗舰版或团队版，完成支付。
  3. 进入控制台复制订阅链接，或按客户端类型下载配置。
  4. 在 Windows、macOS、Android 或 iOS 客户端中导入订阅并更新节点列表。
  5. 选择靠近目标站点的节点测试延迟，再开启系统代理或 TUN 模式。
  6. 若无法播放或延迟偏高，切换线路组或提交工单说明客户端与错误现象。
导入后请先更新订阅再连接。同一订阅在多台设备同时使用会计入在线台数，超出套餐上限时可能挤占较早会话。

客户端下载与订阅导入

NodeCat 兼容主流代理内核与图形客户端。官方下载入口位于登录后的用户中心，请勿从不明网盘或群组获取安装包。

桌面端

Windows 与 macOS 可使用 Clash Meta 内核图形客户端、sing-box 图形前端或官网提供的封装客户端。导入订阅后开启系统代理，浏览器与终端即可走加速通道。如需全局，请在客户端中启用 TUN 并允许必要的网络权限。

移动端

Android 可安装官网 APK 或兼容 Clash / sing-box 的应用。iOS 常用 Shadowrocket、Stash、Quantumult X 等，通过订阅 URL 添加。安装完成后打开自动更新节点，避免使用过期服务器。

订阅与节点

订阅链接绑定当前套餐流量与设备策略。节点池包含普通线路与 IPLC 专线，旗舰版与团队版可使用原生流媒体解锁组。团队版还可按域名或 IP 配置分流，把办公应用与娱乐流量分开。

官方下载与订阅仅在本站用户中心发放。若页面要求额外插件或扫码到非官方域名，请停止操作并改走工单核实。

线路与使用建议

NodeCat 节点覆盖亚太、日韩、欧美等常用方向，晚高峰会进行负载调度。普通线路适合网页与轻量应用；游戏与实时会议优先 IPLC。流媒体解锁随平台策略调整，遇到地区限制时更换同组其他节点通常即可恢复。

流量以实际代理传输计量，含视频缓存与系统更新。建议在客户端开启分应用代理，避免云同步与应用商店占满月度额度。连接异常时先更新订阅、更换 DNS 或关闭冲突的系统 VPN。

常见问题

下面汇总选购、下载、流量与解锁相关问题。展开条目即可阅读说明，内容与当前套餐规则一致。

NodeCat 是什么服务，和普通 VPN 有何不同？

NodeCat 以机场订阅方式提供节点与流量额度，用户可在自选客户端中导入并切换线路。相对单一出口的 VPN 应用，机场模式更便于按地区、流媒体或游戏需求换节点，也方便多设备共用同一订阅。套餐、设备上限与解锁范围以官网公示为准。

如何从官网完成客户端下载并开始加速？

登录 NodeCat 官网用户中心，在下载分区获取 Windows、macOS 或 Android 安装包；iOS 使用兼容商店应用导入订阅。安装后粘贴订阅地址、更新节点，选择延迟较低的线路连接。请只使用官方渠道，避免第三方二次打包。

三个套餐应该怎么选？流量用完会停网吗？

1 至 3 台设备、轻度浏览选基础版；需要原生流媒体、游戏专线或优先工单选旗舰版；20 台设备以内或要定制路由选团队版。当月流量用尽后连接会暂停，不会自动扣费。可升级套餐或等待次月重置，年付只是计价方式优惠，月度额度规则不变。

能否解锁常见流媒体，游戏延迟如何优化？

基础版支持基础流媒体；旗舰版与团队版提供全节点原生解锁，覆盖多数影视与音乐平台。游戏请优先连接 IPLC 专线组并关闭其他占用带宽的下载。实际效果受本地宽带与目标服务器影响，可在客户端内多次测速后固定一条较稳的节点。

同时在线设备如何计算，团队如何分配？

同一账号在不同终端保持连接即计入在线数：基础版 3 台、旗舰版 5 台、团队版 20 台。超出后可能断开最早会话。团队可将订阅分发给成员，或由管理员在定制路由中限制域名。不要把订阅公开到论坛或聊天群，以免被盗用挤占额度。

工单如何提交，旗舰版和团队版支持有何区别？

登录官网后在工单中心提交客户端版本、操作系统、错误截图或日志时间。旗舰版提供 7x24 优先处理，团队版另有专属客户经理跟进定制路由。普通咨询在工作时段回复。请忽略非官方社交账号的代充或远程协助请求。
